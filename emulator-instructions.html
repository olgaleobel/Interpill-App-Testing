Testing Interpill using an Android emulator

These instructions are for participants who do not have an Android phone but are willing to test the Interpill app using a virtual Android device (emulator) on a computer.

Step 1 – Install an Android emulator
Option A (recommended for technical users): Install Android Studio from the official website and create a virtual device (AVD) with any recent Android version.
Option B (simpler, for non-technical users): Install a popular Android emulator such as BlueStacks, LDPlayer or a similar tool for your operating system.
Step 2 – Download the Interpill APK

Download the APK file to your computer from the main download page:

Open the Interpill APK download page

Step 3 – Install the APK in the emulator
1. Start the Android emulator and wait until it has fully loaded.
2. Drag and drop the downloaded APK file onto the emulator window (or use the emulator’s “Install APK” menu option, if available).
3. Follow the on-screen prompts inside the emulator to complete the installation.
4. Open the Interpill app inside the emulator and test it as you would on a normal Android phone.
