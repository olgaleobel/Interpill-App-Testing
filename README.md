## 📄 About the Application

### 🎯 Primary Purpose

**The primary purpose of Interpill is to provide personalised drug–drug interaction checks.**

---

In addition to its core purpose, the application also provides:

- scanning of medication packaging,  
- access to instructions (via RxNorm, OpenFDA, and DailyMed),  
- a medication schedule (calendar) with quick interaction checks for all added medicines.

Interaction analysis is **personalised**, taking into account the user’s recorded allergies and medical conditions.  
It combines information from authoritative pharmaceutical data sources with an **AI-generated summary**, providing an additional high-level interpretation of the interaction findings.

This repository contains the APK file specifically for the **evaluation phase** of the project and does not include the full source code.
